В цій папці треба зробити проект Laravel 13. Подивитися як встановлювати Laravel можна в документації https://laravel.com/framework/docs/installation. Мені треба встановити php 8.5. Також має бути встановлений MySQL версії 8+ та nginx. Все має встановлюватись через Docker, тож підготуй сервіси docker compose. Разом зі встановленням Laravel встанови також проект larastan та підключи його, дотримуючись інструкцій по встановленню https://github.com/larastan/larastan/blob/3.x/README.md
