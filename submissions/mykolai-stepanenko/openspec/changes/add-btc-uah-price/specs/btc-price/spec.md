# Spec Delta

## Purpose

Надає поточну ціну Bitcoin у гривнях (UAH) з кількох зовнішніх провайдерів з автоматичним fallback і видає її через публічний JSON endpoint.

## ADDED Requirements

### Requirement: Endpoint поточної ціни BTC
Система SHALL обслуговувати `GET /api/btc-price` і при успіху повертати HTTP 200 з JSON `{"price": <number>, "currency": "UAH", "provider": "<name>"}`. Тут `price` — додатне число, `provider` — ідентифікатор провайдера, який дав ціну.

#### Scenario: Основний провайдер відповідає
- **WHEN** клієнт викликає `GET /api/btc-price`, а основний провайдер повертає коректну ціну
- **THEN** відповідь має статус 200, `price` дорівнює ціні від основного провайдера, `currency` дорівнює `"UAH"`, а `provider` дорівнює `"coingecko"`

### Requirement: Fallback на наступного провайдера
Система SHALL опитувати провайдерів у налаштованому порядку і повертати результат першого, що дав коректну ціну. Провайдер MUST вважатися таким, що не спрацював, якщо він не відповів у межах timeout, повернув HTTP-помилку, невалідний JSON, або ціни немає, вона нечислова чи ≤ 0. Коли провайдер відповів успішно, наступних провайдерів система MUST NOT опитувати.

#### Scenario: Основний провайдер повертає помилку сервера
- **WHEN** основний провайдер повертає HTTP 500, а резервний повертає коректну ціну
- **THEN** відповідь має статус 200 з ціною від резервного провайдера, а `provider` дорівнює `"coinbase"`

#### Scenario: Основний провайдер повертає некоректну ціну
- **WHEN** основний провайдер повертає ціну `0`, нечислове значення або JSON без поля ціни
- **THEN** система звертається до резервного провайдера і повертає його ціну

#### Scenario: Резервний провайдер не опитується при успіху основного
- **WHEN** основний провайдер повертає коректну ціну
- **THEN** до резервного провайдера запит не надсилається

### Requirement: Недоступність усіх провайдерів
Якщо жоден провайдер не дав коректної ціни, система SHALL повертати HTTP 503 з JSON `{"message": "Bitcoin price is temporarily unavailable."}`. Кожен збій провайдера SHALL записуватися в лог як warning.

#### Scenario: Усі провайдери не спрацювали
- **WHEN** і основний, і резервний провайдер повертають помилку або некоректні дані
- **THEN** відповідь має статус 503 і JSON `{"message": "Bitcoin price is temporarily unavailable."}`
