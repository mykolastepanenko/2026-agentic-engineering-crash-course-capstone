# Spec Delta

## Purpose

Робить головну сторінку застосунку Vue 3 інтерфейсом, який показує користувачу поточну ціну Bitcoin у гривнях з наявного API ціни BTC.

## ADDED Requirements

### Requirement: Головна сторінка віддає Vue-застосунок
Система SHALL на `GET /` повертати HTTP 200 з HTML-сторінкою, що містить точку монтування Vue (`<div id="app">`) і підключає зібрані frontend-ресурси застосунку.

#### Scenario: Відкриття головної сторінки
- **WHEN** користувач відкриває `/`
- **THEN** відповідь має статус 200, HTML містить елемент з `id="app"` і посилання на JS-бандл застосунку

#### Scenario: Vue монтується в браузері
- **WHEN** сторінка `/` завантажилася в браузері зі зібраними ресурсами
- **THEN** вміст `#app` рендерить Vue, а в консолі браузера немає помилок

### Requirement: Віджет поточної ціни BTC
Головна сторінка SHALL після завантаження запитувати `GET /api/btc-price` і показувати ціну в UAH, відформатовану за українською локаллю, разом з назвою провайдера. Поки запит виконується, SHALL показуватися стан завантаження.

#### Scenario: Ціна доступна
- **WHEN** `GET /api/btc-price` повертає 200 з `{"price": 3793253.0, "currency": "UAH", "provider": "coingecko"}`
- **THEN** віджет показує ціну у форматі гривні (наприклад «3 793 253,00 ₴») і провайдера `coingecko`

#### Scenario: Стан завантаження
- **WHEN** запит до `/api/btc-price` ще не завершився
- **THEN** віджет показує індикатор завантаження замість ціни

### Requirement: Недоступність ціни і ручне оновлення
Якщо API повертає помилку (зокрема 503) або запит падає через мережу, віджет SHALL показувати повідомлення «Ціна тимчасово недоступна», а не падати. Віджет SHALL мати кнопку «Оновити», яка повторює запит.

#### Scenario: API повертає 503
- **WHEN** `GET /api/btc-price` повертає 503
- **THEN** віджет показує повідомлення «Ціна тимчасово недоступна» і кнопку «Оновити»

#### Scenario: Ручне оновлення
- **WHEN** користувач натискає «Оновити»
- **THEN** віджет повторно запитує `/api/btc-price` і показує новий результат
