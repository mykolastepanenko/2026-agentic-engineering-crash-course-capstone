# Proposal

## Why

Зараз головна сторінка показує ціну BTC лише за стандартним ланцюжком: спочатку CoinGecko, а якщо він не відповів — Coinbase. Користувач не бачить, скільки дає кожне джерело, і не може обрати його сам. Потрібні кнопки, які за бажанням користувача показують ціну від конкретного провайдера. Поведінка за замовчуванням лишається без змін.

## What Changes

- `GET /api/btc-price` приймає необов'язковий параметр `?provider=<name>` (`coingecko` | `coinbase`):
  - без параметра поведінка та сама, що зараз (ланцюжок fallback, формат відповіді не змінюється);
  - з параметром ціна береться **лише** від обраного провайдера, без fallback; якщо він не відповів, повертається `503`;
  - невідомий провайдер дає `422` з помилкою валідації.
- У віджеті на головній сторінці з'являються кнопки «Авто», «CoinGecko», «Coinbase»:
  - при завантаженні активна «Авто» (поточна поведінка);
  - натискання на провайдера запитує ціну саме від нього;
  - активна кнопка підсвічена;
  - «Оновити» повторює запит для поточного вибору.
- Якщо обраний провайдер недоступний, віджет показує повідомлення з назвою провайдера.
